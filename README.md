# Tear Drop Memorial - High-Resolution Orthomosaic

**Author:** Youssef Elshenawy  

## Project Overview
This project features a high-resolution 2D mapping mission of the Tear Drop Memorial area in Bayonne, NJ. The primary objective was to capture and process nadir imagery to generate a highly accurate orthomosaic for GIS integration and spatial analysis.

## Hardware & Software
* **UAS Platform:** DJI Matrice 4 Enterprise (M4E)
* **Processing Engine:** WebODM
* **Deliverables Generated:** RGB Orthomosaic (GeoTIFF), Point Cloud, Processing Quality Report
